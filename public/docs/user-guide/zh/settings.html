系统设置

系统设置

用户与权限组

前往 系统设置 → 用户 管理团队的访问权限：

  • 邀请用户 — 输入邮箱地址后，用户将收到设置密码的邀请链接
  • 分配权限组 — 权限组根据用户角色定义权限（运营、财务、管理员）
  • 停用用户 — 将用户切换为非活跃状态，在不删除历史记录的情况下撤销其访问权限

前往 系统设置 → 权限组 管理权限组。对于每个权限组，您可以自定义每个模块允许执行的操作（查看、创建、编辑、删除）。

全局设置

前往 系统设置 → 全局设置 配置组织级别的默认值：

  • 基础货币 — 用于 P&L 和报表的默认货币
  • 汇率 — 设置和更新多币种单据使用的外汇汇率
  • 报价单编号格式 — 报价单号的自动编号格式（例如 QT-{YYYY}-{SEQ}）
  • 货运订单编号格式 — 作业编号的自动编号格式

公司信息

前往 系统设置 → 公司 管理您组织的基本信息：

  • 公司名称、徽标及注册地址
  • 法律注册信息（公司注册号、税务识别号）
  • 发票和付款说明中使用的银行账户信息
提示： 公司徽标和详情将显示在所有生成的 PDF 文件中——包括发票、报价单、装箱单和 SOA。请保持此信息为最新状态。

分公司与部门

分公司 代表您的实体办公地点。每个货运订单、发票和财务单据均可分配至分公司，从而支持分公司级别的报表和 P&L 核算。

部门 是分公司内的成本中心，适用于部门级 P&L 报告和预算分配。

科目表

前往 系统设置 → 科目表 定义您的 GL（总账）账户结构，涵盖资产、负债、权益、收入和费用。这些账户编码用于日记账分录和财务报告。

EDI 集成

前往 系统设置 → 集成连接器 配置与承运商系统、追踪服务商和贸易平台的连接。每个连接器需要：

  • 承运商或数据提供商提供的 API 凭证
  • 将承运商状态代码转换为系统状态的数据映射规则
  • 验证集成是否处于活跃和响应状态的连接测试
Note: EDI connectors require IT or admin-level setup. Contact your system administrator or Make Cargo support when adding new integrations.

个人档案

点击任意页面右上角的头像，访问个人档案设置。在此您可以：

  • 更新您的姓名、邮箱地址和头像
  • 修改密码
  • 设置您的首选语言
  • 配置通知偏好设置
