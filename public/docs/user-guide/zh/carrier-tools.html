承运商工具

承运商工具

与承运商系统集成的实时船期查询和集装箱追踪工具。

船期时刻表

前往 承运商 → 船期查询。使用 UN/LOCODE 代码输入 POL 和 POD（例如，胡志明市为 VNCLI），可选择设置 ETD 开始日期，然后点击 搜索。

搜索结果显示：

  • 船名与航次号
  • 承运商名称
  • ETD（预计离港时间）和 ETA（预计到港时间）
  • 在途天数

默认情况下，搜索范围覆盖未来 60 天内的船期。

航班时刻表

前往 承运商 → 航班时刻表。使用 IATA 机场代码输入出发地和目的地（例如，胡志明市为 SGN，香港为 HKG），并选择日期。点击 搜索 查看可用航班、起降时间及中转路线。

集装箱追踪

前往 承运商 → 集装箱追踪，查看系统中所有集装箱的实时追踪状态。列表显示：

  • 货运订单参考号与承运商
  • 集装箱号
  • 当前追踪状态及最新事件描述
  • 最后查询时间戳及承运商 API 错误信息

点击 刷新，立即触发所有已连接承运商的全部追踪集装箱状态更新。
