仪表盘

仪表盘

仪表盘是您的实时运营概览，反映当前业务状态。

统计卡片

七张统计卡片即时汇总您的货运订单组合：

  • 进行中 — 当前正在处理的货运订单
  • 待处理 — 等待确认或操作的货运订单
  • 已确认 — 已预订并确认的订单
  • 即将到达（未来 7 天） — ETA 在一周内的货运订单
  • 已逾期 — 超过预期交货日期的货运订单
  • 异常 — 标记了问题或延误的货运订单
  • 已完成（本月） — 在当前日历月完成的货运订单
提示： 点击任意统计卡片，可直接跳转至经过筛选的货运订单列表，仅显示符合该状态的订单。

月度趋势图

柱状图按月显示货运量，直观呈现增长趋势或季节性波动。将鼠标悬停在柱上可查看该月的确切数量。
