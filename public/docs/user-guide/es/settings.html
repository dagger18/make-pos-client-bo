Configuración

Usuarios y grupos

Vaya a Configuración → Usuarios para gestionar el acceso de su equipo:

  • Invitar usuario — ingrese la dirección de correo electrónico y el usuario recibirá un enlace de invitación para establecer su contraseña
  • Asignar grupos — los grupos definen permisos que corresponden al rol del usuario (Operaciones, Finanzas, Administración)
  • Desactivar usuario — cambie un usuario a Inactivo para revocar el acceso sin eliminar sus registros históricos

Vaya a Configuración → Grupos para gestionar los grupos de permisos. Para cada grupo puede personalizar qué acciones (ver, crear, editar, eliminar) están permitidas en cada módulo.

Configuración global

Vaya a Configuración → Ajuste global para los valores predeterminados de toda la organización:

  • Moneda base — la moneda predeterminada utilizada para PyG e informes
  • Tipos de cambio — establecer y actualizar los tipos de cambio utilizados para documentos multidivisa
  • Formato de ID de cotización — formato de numeración automática para los números de cotización (p. ej., QT-{YYYY}-{SEQ})
  • Formato de ID de envío — formato de numeración automática para los números de trabajo

Información de la empresa

Vaya a Configuración → Empresa para gestionar la identidad de su organización:

  • Nombre de la empresa, logotipo y dirección registrada
  • Datos de registro legal (número de empresa, identificación fiscal)
  • Información bancaria utilizada en facturas e instrucciones de pago
Consejo: El logotipo y los datos de la empresa aparecen en todos los documentos PDF generados: facturas, cotizaciones, listas de empaque y SOAs. Mantenga esta información actualizada.

Sucursales y departamentos

Las sucursales representan sus ubicaciones físicas de oficina. Cada envío, factura y documento financiero puede asignarse a una sucursal, lo que permite informes y PyG a nivel de sucursal.

Los departamentos son centros de costo dentro de una sucursal, útiles para los informes de PyG a nivel departamental y la asignación de presupuesto.

Plan de cuentas

Vaya a Configuración → Plan de cuentas para definir la estructura de cuentas del libro mayor (GL), que cubre activos, pasivos, patrimonio, ingresos y gastos. Estos códigos de cuenta se utilizan para los asientos contables y la presentación de informes financieros.

Integraciones EDI

Vaya a Configuración → Conectores de integración para configurar las conexiones con los sistemas de transportistas, proveedores de seguimiento y plataformas comerciales. Cada conector requiere:

  • Credenciales de API proporcionadas por el transportista o proveedor de datos
  • Reglas de mapeo de datos para traducir los códigos de estado del transportista en estados del sistema
  • Una prueba de conexión para verificar que la integración está activa y respondiendo
Note: EDI connectors require IT or admin-level setup. Contact your system administrator or Make Cargo support when adding new integrations.

Su perfil

Haga clic en su avatar en la esquina superior derecha de cualquier página para acceder a la configuración de su perfil. Desde aquí puede:

  • Actualice su nombre, dirección de correo electrónico y foto de perfil
  • Cambiar su contraseña
  • Establecer su idioma preferido
  • Configurar las preferencias de notificación
