ダッシュボード

ダッシュボードは、現在のビジネス状況をリアルタイムで概観するオペレーション画面です。

統計カード

7 枚の統計カードが輸送ポートフォリオの概要を即座に表示します：

  • 進行中（Active） — 現在進行中の輸送
  • 保留中（Pending） — 確認または対応待ちの輸送
  • 確定済み（Confirmed） — 予約・確定された案件
  • 到着予定（次の 7 日間） — 1 週間以内に ETA がある輸送
  • 期限超過（Overdue） — 納期を過ぎた輸送
  • 例外（Exceptions） — 問題や遅延が報告された輸送
  • 完了（今月） — 当月中に完了した輸送
ヒント： 統計カードをクリックすると、そのステータスに一致する輸送のみを表示したフィルタリング済みの輸送一覧に直接移動します。

月別トレンドチャート

棒グラフが月別の輸送量を表示し、成長トレンドや季節的な落ち込みを視覚的に確認できます。棒グラフにカーソルを合わせると、その月の正確な件数が表示されます。

近日到着予定

テーブルは今後 7 日以内に ETA がある全輸送を一覧表示し、オペレーションスタッフが入荷貨物の計画を立てるのに役立ちます。

進行中の輸送

クイックビューパネルには、進行中のすべての案件の現在のステータスと担当クライアントが表示されます。任意の行をクリックすると、輸送の詳細全体が開きます。
