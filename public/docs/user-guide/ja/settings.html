設定

ユーザー & グループ

チームのアクセス権を管理するには、設定 → ユーザー に移動してください：

  • ユーザーを招待 — メールアドレスを入力すると、そのユーザーにパスワード設定のための招待リンクが送信されます
  • グループを割り当て — グループはユーザーの役割（オペレーション、財務、管理者）に応じた権限を定義します
  • ユーザーを無効化 — ユーザーを無効に切り替えることで、過去の記録を削除せずにアクセスを取り消します

権限グループを管理するには、設定 → グループ に移動してください。各グループについて、各モジュールで許可するアクション（閲覧、作成、編集、削除）をカスタマイズできます。

グローバル設定

組織全体のデフォルト設定を行うには、設定 → グローバル設定 に移動してください：

  • 基本通貨 — P&L とレポートに使用されるデフォルト通貨
  • 為替レート — マルチ通貨書類に使用される為替レートを設定・更新します
  • 見積もり ID フォーマット — 見積もり番号の自動採番フォーマット（例：QT-{YYYY}-{SEQ}）
  • 輸送 ID フォーマット — 案件番号の自動採番フォーマット

会社情報

組織の会社情報を管理するには、設定 → 会社 に移動してください：

  • 会社名、ロゴ、登記住所
  • 法人登記の詳細（会社番号、税務 ID）
  • 請求書や支払い指示に使用する銀行情報
ヒント： 会社のロゴと詳細は、生成されるすべての PDF 書類（請求書、見積もり、梱包明細書、SOA）に表示されます。この情報を最新の状態に保ってください。

支店 & 部門

支店（Branches） は実際のオフィスの場所を表します。各輸送、請求書、財務書類を支店に割り当てることができ、支店レベルのレポートと P&L が可能になります。

部門（Departments） は支店内のコストセンターで、部門レベルの P&L レポートと予算配分に役立ちます。

勘定科目表

設定 → 勘定科目表 に移動して、資産、負債、資本、収益、費用をカバーする GL（総勘定元帳）の勘定体系を定義してください。これらの勘定コードは仕訳入力と財務報告に使用されます。

EDI 連携

キャリアシステム、追跡プロバイダー、貿易プラットフォームとの接続を設定するには、設定 → 連携コネクター に移動してください。各コネクターには以下が必要です：

  • キャリアまたはデータプロバイダーから提供される API 認証情報
  • キャリアのステータスコードをシステムステータスに変換するデータマッピングルール
  • 連携がアクティブで応答していることを確認する接続テスト
Note: EDI connectors require IT or admin-level setup. Contact your system administrator or Make Cargo support when adding new integrations.

プロフィール

任意のページの右上にあるアバターをクリックして、プロフィール設定にアクセスします。ここでは以下が行えます：

  • 名前、メールアドレス、プロフィール写真を更新します
  • パスワードを変更します
  • 使用言語を設定します
  • 通知の設定を行います
