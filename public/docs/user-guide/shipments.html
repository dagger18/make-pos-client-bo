Shipments

Shipments are the core operational unit. Each represents one freight job from origin to destination.

Creating a Shipment

  1. 1Go to Shipments, select a transport mode tab, or click New Shipment from the Dashboard
  2. 2Choose transport mode and service type (FCL, LCL, FTL, LTL, etc.)
  3. 3Enter client, POL (Port of Loading), POD (Port of Discharge), ETD, and ETA
  4. 4Add cargo details: commodity, container count, weight, volume
  5. 5Click Save. The shipment is created with status Draft.

Shipment Statuses

Draft Booked In Transit Delivered Cancelled

Invoicing & Billing

All billing actions are initiated from the Cost Sheet tab of a shipment:

  • Generate Debit Note (ID) — charge the client for sell-side charges
  • Generate Credit Note (IC) — record vendor cost from a provider
  • View P&L — see revenue vs. cost and gross margin for the shipment
  • Close Accounting — lock the cost sheet once billing is finalised

Replicating a Shipment

Use the Replicate action on any shipment to create a new Draft pre-filled with the same details — client, route, cargo, and charge lines. This is useful for recurring trade lanes with the same client.

Manifest

Navigate to Shipments → Manifest to generate a cargo manifest report across multiple shipments for a given vessel or flight. The manifest can be exported as PDF or Excel for submission to carriers or port authorities.
