الموردون

SOA المورد

يمتلك كل مورد كشف حساب يعرض جميع فواتير التكاليف (IC) والمدفوعات المقدَّمة لهذا المورد. استخدمه لتتبع الذمم الدائنة المعلّقة والتسوية مع كشوف حسابات الموردين.

يمكنك التصفية حسب النطاق الزمني وتحديد عملة العرض وتصدير البيانات كـ PDF أو Excel للتسوية مع فريق الذمم الدائنة.
