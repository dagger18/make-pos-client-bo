المحاسبة

تتعامل وحدة المحاسبة مع جميع المستندات المالية — الفواتير والإشعارات الدائنة والمدفوعات والإيصالات.

أنواع المستندات

CodeNamePurpose
IDDebit Note / Sales InvoiceCharge a client for freight services
ICCredit Note / Cost InvoiceRecord cost from a provider
COCOBOInternal cost-to-owner document
POPOBO / Purchase OrderPurchase order / payable record
PMTPaymentRecord a payment made to a provider
RPTReceiptRecord a payment received from a client

إنشاء فاتورة (ID)

  1. 1Go to Accounting → ID and click New Invoice, or create directly from the shipment Cost Sheet tab
  2. 2Select the client and shipment reference
  3. 3Add charge lines (imported from cost sheet or entered manually)
  4. 4Set the currency and exchange rate
  5. 5Save as Draft, then click Submit to finalise and issue to the client

كشف الحساب

انتقل إلى المحاسبة → SOA-Client أو افتح سجل عميل/مورد وحدد كشف الحساب. يعرض SOA:

  • جميع الفواتير وحالتها الحالية (مسودة / مقدّمة / معتمدة / مدفوعة)
  • جميع المدفوعات والفواتير التي طُبِّقت عليها
  • الرصيد المستحق الجاري
  • عرض متعدد العملات مع أسعار صرف قابلة للتعديل

صدّر كشف الحساب بصيغة PDF أو Excel لمراجعة العميل أو التسوية الداخلية.

تسجيل المدفوعات والإيصالات

انتقل إلى المحاسبة → PMT لتسجيل مدفوعات للمورد، أو المحاسبة → RPT لتسجيل مدفوعات مستلمة من عميل. في كل حالة:

  1. أنشئ سجلاً جديداً وربطه بالفاتورة (الفواتير) المعنية
  2. أدخل مبلغ الدفع والتاريخ وطريقة الدفع (تحويل بنكي، بطاقة، شيك، إلخ)
  3. احفظ — يتحدّث الرصيد المستحق للفاتورة (الفواتير) المرتبطة تلقائياً

تقارير الديون المتأخرة

انتقل إلى المحاسبة → AR Ageing (المستحقات) أو AP Ageing (الذمم الدائنة). حدد نطاقاً زمنياً وشغّل التقرير. تُجمَّع المبالغ المستحقة حسب فئة التأخر:

Current 1–30 days 31–60 days 61–90 days 90+ days

قيود اليومية

انتقل إلى المحاسبة → اليومية لإنشاء قيود دفتر الأستاذ اليدوية. تتطلب كل قيد يومية:

  • رموز حسابات المدين والدائن من دليل الحسابات
  • الوصف والمرجع
  • المبلغ والعملة

تتطلب قيود اليومية موافقة من مستخدم مفوّض قبل ترحيلها إلى دفتر الأستاذ العام.

الأرباح والخسائر حسب الفترة

انتقل إلى المحاسبة → فترة الأرباح والخسائر. حدد نطاق تاريخ من/إلى وانقر تشغيل التقرير. يعرض التقرير الإيرادات والتكاليف والربح الإجمالي والهامش % وأرباح/خسائر العملات الأجنبية والربح الصافي مقسمة حسب الفرع.
