أدوات الناقلين

أدوات استعلام الجدول الزمني الفوري وتتبع الحاويات المتكاملة مع أنظمة الناقلين.

جدول إبحار السفن

انتقل إلى الناقلون → إبحار السفينة. أدخل POL وPOD باستخدام رموز UN/LOCODE (مثلاً VNCLI لمدينة هو تشي منه)، وحدد اختيارياً تاريخ بدء ETD، وانقر بحث.

تعرض النتائج:

  • اسم السفينة ورقم الرحلة
  • اسم الناقل
  • ETD (وقت المغادرة التقديري) وETA (وقت الوصول التقديري)
  • وقت العبور بالأيام

يغطي البحث بشكل افتراضي الإبحارات حتى 60 يوماً مقدماً.

جدول الرحلات

انتقل إلى الناقلون → جدول الرحلات. أدخل المطار المغادر والوجهة باستخدام رموز IATA (مثلاً SGN لمدينة هو تشي منه، HKG لهونغ كونغ) وحدد التاريخ. انقر بحث لعرض الرحلات المتاحة وأوقات المغادرة والوصول وأي خطوط عبور.

تتبع الحاويات

انتقل إلى الناقلون → تتبع الحاويات لعرض حالة التتبع الفوري لجميع الحاويات الموجودة حالياً في نظامك. تعرض القائمة:

  • مرجع الشحنة والناقل
  • رقم الحاوية
  • حالة التتبع الحالية ووصف آخر حدث
  • طابع زمني لآخر فحص وأي أخطاء API للناقل

انقر تحديث لتشغيل تحديث فوري للحالة لجميع الحاويات المتتبَّعة عبر جميع الناقلين المتصلين.
