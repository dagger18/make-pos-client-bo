الأسعار

خزّن قوائم أسعار الشراء والبيع. تُعبّئ الأسعار تلقائياً بنود الرسوم في عروض الأسعار والشحنات، مما يوفر الوقت ويقلل أخطاء الإدخال اليدوي.

فئات الرسوم

CategoryExamples
FreightOcean freight (per TEU/CBM), air freight (per kg), trucking rate
LocalTHC (Terminal Handling Charge), documentation fee, port congestion surcharge
CustomsCustoms clearance fee, duty handling, inspection fee
ServiceInsurance, fumigation, labelling, palletising

إضافة سعر

  1. 1Go to Rates, select a charge type (Freight / Local / Customs / Service) and transport mode tab
  2. 2Click New Rate
  3. 3Enter origin/destination, carrier, currency, rate amount, and effective date range
  4. 4Click Save. The rate is now available when building quotes and shipments.

استيراد الأسعار

انتقل إلى الأسعار → استيراد لرفع الأسعار بشكل مجمّع من جدول بيانات. مفيد عند تحديث التعريفات المستلمة من ناقل أو وكيل خارجي. نزّل قالب الاستيراد وأدخل أسعارك وارفع الملف.

قواعد هامش الربح

حدّد نسب هامش الربح التلقائية أو المبالغ الثابتة التي تُضاف إلى أسعار الشراء. انتقل إلى الأسعار → هامش الربح وأنشئ قواعد تستهدف فئات عملاء أو خطوط تجارية أو أنواع رسوم محددة. تُطبَّق قواعد هامش الربح تلقائياً عند إنشاء بنود رسوم جانب البيع.
