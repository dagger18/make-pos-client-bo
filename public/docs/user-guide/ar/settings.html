الإعدادات

المستخدمون والمجموعات

انتقل إلى الإعدادات → المستخدمون لإدارة وصول فريقك:

  • دعوة مستخدم — أدخل عنوان البريد الإلكتروني وسيتلقى المستخدم رابط دعوة لتعيين كلمة مروره
  • تعيين مجموعات — تحدد المجموعات الصلاحيات المتوافقة مع دور المستخدم (العمليات، المالية، المشرف)
  • تعطيل مستخدم — اجعل المستخدم غير نشط لإلغاء وصوله دون حذف سجلاته التاريخية

انتقل إلى الإعدادات → المجموعات لإدارة مجموعات الصلاحيات. يمكنك لكل مجموعة تخصيص الإجراءات المسموح بها (عرض، إنشاء، تعديل، حذف) لكل وحدة.

الإعدادات العامة

انتقل إلى الإعدادات → الإعداد العام للإعدادات الافتراضية على مستوى المؤسسة:

  • العملة الأساسية — العملة الافتراضية المستخدمة للأرباح والخسائر والتقارير
  • أسعار الصرف — تعيين أسعار العملات الأجنبية وتحديثها للمستندات متعددة العملات
  • تنسيق معرّف عرض السعر — تنسيق الترقيم التلقائي لأرقام عروض الأسعار (مثلاً QT-{YYYY}-{SEQ})
  • تنسيق معرّف الشحنة — تنسيق الترقيم التلقائي لأرقام المهام

معلومات الشركة

انتقل إلى الإعدادات → الشركة لإدارة هوية مؤسستك:

  • اسم الشركة والشعار والعنوان المسجّل
  • تفاصيل التسجيل القانوني (رقم الشركة، الرقم الضريبي)
  • معلومات بنكية تُستخدم في الفواتير وتعليمات الدفع
تلميح: يظهر شعار الشركة وتفاصيلها على جميع مستندات PDF المُنشأة — الفواتير وعروض الأسعار وقوائم التعبئة وSOAs. احرص على تحديث هذه المعلومات.

الفروع والأقسام

الفروع تمثّل مواقع مكاتبك الفعلية. يمكن تعيين كل شحنة وفاتورة ومستند مالي لفرع، مما يتيح التقارير على مستوى الفروع والأرباح والخسائر.

الأقسام هي مراكز تكلفة داخل الفرع، مفيدة لتقارير الأرباح والخسائر على مستوى القسم وتخصيص الميزانية.

دليل الحسابات

انتقل إلى الإعدادات → دليل الحسابات لتعريف هيكل حسابات دفتر الأستاذ العام (GL)، الذي يشمل الأصول والخصوم وحقوق الملكية والإيرادات والمصروفات. تُستخدم هذه الرموز للقيود اليومية والتقارير المالية.

تكاملات EDI

انتقل إلى الإعدادات → موصلات التكامل لتكوين الاتصالات بأنظمة الناقلين ومزودي التتبع والمنصات التجارية. يتطلب كل موصل:

  • بيانات اعتماد API المقدَّمة من الناقل أو مزود البيانات
  • قواعد ربط البيانات لترجمة رموز حالة الناقل إلى حالات النظام
  • اختبار اتصال للتحقق من أن التكامل نشط ويستجيب
Note: EDI connectors require IT or admin-level setup. Contact your system administrator or Make Cargo support when adding new integrations.

ملف تعريفك

انقر على صورة ملف تعريفك في الزاوية العلوية اليمنى لأي صفحة للوصول إلى إعدادات ملفك. من هنا يمكنك:

  • تحديث اسمك وعنوان بريدك الإلكتروني وصورة ملف تعريفك
  • تغيير كلمة المرور
  • تعيين لغتك المفضلة
  • ضبط تفضيلات الإشعارات
