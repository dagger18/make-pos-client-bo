혼재

혼재는 여러 LCL（또는 혼재）화물을 하나의 컨테이너 또는 항공편으로 묶어 모든 화주가 운임을 분담합니다.

혼재 생성

  1. 1Go to Consolidations and click New Consolidation
  2. 2Select transport mode and service type (e.g., Ocean — LCL)
  3. 3Enter POL, POD, ETD, ETA, vessel/flight details, and container/ULD details
  4. 4Go to the Manifest tab and search for existing LCL shipments to attach as child shipments

혼재 상태

Open Closed Departed Arrived Cancelled

적입 & 적출

적입（Stuffing）은 출발지에서의 컨테이너 적재 과정을 기록합니다. 각 화물 품목과 상태가 컨테이너에 적재될 때 기록됩니다.

적출（Stripping）은 목적지 CFS（Container Freight Station）에서의 화물 하역 과정을 기록합니다. 화물이 확인되고 각 수하인에게 배정됩니다. 각 개별 운송의 화물 품목이 이 과정을 통해 추적됩니다.

팁： 새 운송이 추가되지 않도록 출발 전에 혼재를 마감하세요. 선박이 출항하면 혼재를 출항됨으로, 목적지에서 화물이 수령되면 도착됨으로 표시하세요.
