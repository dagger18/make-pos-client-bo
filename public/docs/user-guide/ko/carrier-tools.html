운송사 도구

운송사 시스템과 연동된 실시간 스케줄 조회 및 컨테이너 추적 도구.

선박 운항 스케줄

운송사 → 선박 스케줄로 이동하세요. UN/LOCODE 코드를 사용하여 POL과 POD를 입력하고（예：호치민시는 VNCLI）, 필요에 따라 ETD 시작일을 설정한 후 검색을 클릭합니다.

검색 결과에는 다음이 표시됩니다：

  • 선박명 및 항차 번호
  • 운송사명
  • ETD（출항 예정일시）및 ETA（입항 예정일시）
  • 운송 소요 일수

검색은 기본적으로 60일 이내의 출항을 대상으로 합니다.

항공 스케줄

운송사 → 항공 스케줄로 이동하세요. IATA 공항 코드를 사용하여 출발지와 목적지를 입력하고（예：호치민시는 SGN，홍콩은 HKG）날짜를 선택합니다. 검색을 클릭하면 이용 가능한 항공편, 출발·도착 시간, 경유 노선을 확인할 수 있습니다.

컨테이너 추적

운송사 → 컨테이너 추적으로 이동하여 시스템에 있는 모든 컨테이너의 실시간 추적 상태를 확인하세요. 목록에는 다음이 표시됩니다：

  • 운송 참조 번호 및 운송사
  • 컨테이너 번호
  • 현재 추적 상태 및 최근 이벤트 설명
  • 마지막 확인 시간 및 운송사 API 오류

새로 고침을 클릭하면 연결된 모든 운송사의 추적 컨테이너 상태가 즉시 업데이트됩니다.
