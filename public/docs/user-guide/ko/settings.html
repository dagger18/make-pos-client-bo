사용자 & 그룹

팀의 접근 권한을 관리하려면 설정 → 사용자로 이동하세요：

  • 사용자 초대 — 이메일 주소를 입력하면 해당 사용자에게 비밀번호 설정을 위한 초대 링크가 전송됩니다
  • 그룹 배정 — 그룹은 사용자의 역할（운영, 재무, 관리자）에 맞는 권한을 정의합니다
  • 사용자 비활성화 — 사용자를 비활성으로 전환하여 기존 기록을 삭제하지 않고 접근 권한을 취소합니다

권한 그룹을 관리하려면 설정 → 그룹으로 이동하세요. 각 그룹에 대해 각 모듈에서 허용되는 작업（보기, 생성, 편집, 삭제）을 사용자 정의할 수 있습니다.

전역 설정

조직 전체 기본값을 설정하려면 설정 → 전역 설정으로 이동하세요：

  • 기본 통화 — P&L 및 보고에 사용되는 기본 통화
  • 환율 — 다중 통화 문서에 사용되는 환율을 설정하고 업데이트합니다
  • 견적 ID 형식 — 견적 번호의 자동 채번 형식（예：QT-{YYYY}-{SEQ}）
  • 운송 ID 형식 — 건 번호의 자동 채번 형식

회사 정보

조직의 회사 정보를 관리하려면 설정 → 회사로 이동하세요：

  • 회사명, 로고, 등기 주소
  • 법인 등록 정보（회사 번호, 세무 ID）
  • 인보이스 및 결제 안내에 사용되는 은행 정보
팁： 회사 로고와 정보는 생성되는 모든 PDF 문서（인보이스, 견적서, 포장 명세서, SOA）에 표시됩니다. 이 정보를 최신 상태로 유지하세요.

지점 & 부서

지점（Branches）은 실제 사무소 위치를 나타냅니다. 각 운송, 인보이스, 재무 문서를 지점에 배정할 수 있어 지점 수준의 보고서 및 P&L이 가능합니다.

부서（Departments）는 지점 내 비용 센터로, 부서 수준의 P&L 보고 및 예산 배분에 유용합니다.

계정과목표

설정 → 계정과목표로 이동하여 자산, 부채, 자본, 수익, 비용을 포함하는 GL（총계정원장）계정 구조를 정의하세요. 이 계정 코드는 분개 입력과 재무 보고에 사용됩니다.

EDI 연동

운송사 시스템, 추적 공급업체, 무역 플랫폼과의 연결을 구성하려면 설정 → 연동 커넥터로 이동하세요. 각 커넥터에는 다음이 필요합니다：

  • 운송사 또는 데이터 공급업체가 제공하는 API 인증 정보
  • 운송사 상태 코드를 시스템 상태로 변환하는 데이터 매핑 규칙
  • 연동이 활성화되어 응답하는지 확인하는 연결 테스트
Note: EDI connectors require IT or admin-level setup. Contact your system administrator or Make Cargo support when adding new integrations.

내 프로필

임의 페이지의 오른쪽 상단에 있는 아바타를 클릭하여 프로필 설정에 접근합니다. 여기에서 다음을 할 수 있습니다：

  • 이름, 이메일 주소, 프로필 사진을 업데이트합니다
  • 비밀번호를 변경합니다
  • 선호 언어를 설정합니다
  • 알림 기본 설정을 구성합니다
