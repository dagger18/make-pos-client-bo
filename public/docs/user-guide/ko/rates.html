운임

구매·판매 요금표를 저장합니다. 운임은 견적 및 운송의 요금 항목에 자동으로 채워져 시간을 절약하고 수동 입력 오류를 줄입니다.

요금 카테고리

CategoryExamples
FreightOcean freight (per TEU/CBM), air freight (per kg), trucking rate
LocalTHC (Terminal Handling Charge), documentation fee, port congestion surcharge
CustomsCustoms clearance fee, duty handling, inspection fee
ServiceInsurance, fumigation, labelling, palletising

운임 추가

  1. 1Go to Rates, select a charge type (Freight / Local / Customs / Service) and transport mode tab
  2. 2Click New Rate
  3. 3Enter origin/destination, carrier, currency, rate amount, and effective date range
  4. 4Click Save. The rate is now available when building quotes and shipments.

운임 가져오기

운임 → 가져오기로 이동하여 스프레드시트에서 운임을 일괄 업로드합니다. 운송사나 해외 대리점에서 받은 운임을 업데이트할 때 유용합니다. 가져오기 템플릿을 다운로드하고 운임을 입력한 후 파일을 업로드합니다.

마크업 규칙

구매 운임 위에 적용할 자동 마크업 비율 또는 고정 금액을 정의합니다. 운임 → 마크업으로 이동하여 특정 클라이언트 등급, 무역 노선, 요금 유형을 대상으로 하는 규칙을 만듭니다. 마크업 규칙은 판매 측 요금 항목 생성 시 자동으로 적용됩니다.
