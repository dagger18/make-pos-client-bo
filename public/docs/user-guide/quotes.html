Quotes

Create and manage shipping quotations. A Quote can be converted into a Shipment once accepted.

Creating a Quote

  1. 1Go to Quotes in the sidebar and select a transport mode tab (Ocean, Air, Road, etc.)
  2. 2Click New Quote
  3. 3Fill in the client, origin/destination, cargo details, and preferred service type
  4. 4Add charge lines (freight, local, customs, service fees). The system can auto-populate from the rate library.
  5. 5Click Save as Draft to save for later, or click Send to issue the quotation to the client.

Quote Statuses

Draft Sent Accepted Rejected Expired

Converting to a Shipment

Open an Accepted quote and click Convert to Shipment. The system creates a new shipment pre-filled with the quote details — client, route, cargo, and charge lines. Review the details and confirm to complete the conversion.

Quote Documents

The Preview PDF button generates a printable quotation document ready to send to the client. You can customise the document header (logo, company details, footer text) via Global Settings.
