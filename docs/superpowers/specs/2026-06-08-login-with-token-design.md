# Login With Token Page — Design Spec

**Date:** 2026-06-08  
**Status:** Approved

## Overview

A new page that auto-logs a user into the BO when they visit a one-click login link generated by the backend. No form interaction is needed — the page decodes URL params, calls the API, and redirects on success.

## URL Structure

Generated by `OrganizationController::getLoginLink`:

```
{client_fe_url}/client-{orgToken}/login-with-token/{base64UrlToken}/{base64UrlEmail}
```

- `base64UrlToken` = `urlencode(base64_encode(hash_hmac('sha256', loginToken, orgToken)))`
- `base64UrlEmail` = `urlencode(base64_encode(userEmail))`

The Vue router base is `client-{orgToken}/` (extracted dynamically when `VITE_CLIENT_MODE === 'shared'`), so the page route is `/login-with-token/:token/:email`.

## File

`src/pages/login-with-token/[token]/[email].vue`

## Page Meta

```js
definePage({
  meta: {
    layout: 'blank',
    unauthenticatedOnly: true,
  },
})
```

## Logic

On `onMounted`:

1. Decode params: `atob(route.params.token)`, `atob(route.params.email)`
2. POST to `/login-with-token` with `{ token, email }`, using `noPushMessage: true`
3. Success (`response.accessToken` present): call `authStore.login(response, route)` → redirects to dashboard
4. Failure (`response.result === 'invalid token'` or any error): set `error = true`, stop loading

## API Endpoint

`POST /api/login-with-token`

Request body: `{ token: string, email: string }`

Success response: `{ accessToken, user, userAbilityRules }` — identical shape to normal login.

Failure response: `{ result: 'invalid token' }`

## Template

Two-column blank auth layout (illustration left, card right) — same as `login.vue`.

**Loading state** (default on mount):
- Centered `VProgressCircular` spinner
- Text: "Logging you in…"

**Error state** (after failed API call):
- Heading: "Invalid or expired login link"
- `RouterLink` to `/login`: "Go to Login"

## Out of Scope

- No "remember me" or any form inputs
- No manual token entry fallback
- No resend-link feature
